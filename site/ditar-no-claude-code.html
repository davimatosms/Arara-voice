Ditar prompts no Claude Code

Explique a tarefa em voz alta, em português, e o Arara cola o prompt inteiro na caixa do Claude Code. Funciona no terminal do Windows e do Mac, sem mandar a sua voz para a nuvem.

O problema

Prompt bom para agente de código é longo: o contexto, o que fazer, o que não mexer e como testar. Digitar tudo isso a cada pedido cansa, e o resultado costuma ser um prompt curto demais, que obriga o agente a adivinhar.

Falando, você explica como explicaria para um colega. Meio minuto de fala vira um parágrafo completo, e o agente erra menos porque recebeu o contexto inteiro.

Como usar

  1. Baixe e instale o Arara (botões no fim da página). Na primeira vez ele baixa o modelo de voz (o “Preciso”, Whisper large-v3-turbo, tem cerca de 550 MB) e depois fica na bandeja do Windows ou na barra de menus do Mac.
  2. Abra o Claude Code no terminal (Windows Terminal, PowerShell, Terminal do macOS, iTerm) ou no terminal do VS Code, com o cursor na caixa de prompt.
  3. Aperte Ctrl + Shift + Espaço e fale. O pop-up mostra o texto ao vivo enquanto você fala. (o atalho é configurável, até uma tecla só; no modo Segurar para falar, você fala enquanto segura).
  4. Aperte Ctrl + Shift + Espaço de novo. O Arara transcreve e cola o texto de uma vez, sem digitar letra por letra.
  5. Revise, acrescente um @arquivo se quiser e aperte Enter. O Arara cola, mas não envia.

O atalho foi escolhido testando no terminal: combinações como Ctrl + Alt + Espaço chegam ao terminal como Esc, e Ctrl + Alt + D manda um Ctrl+D ao terminal. Ctrl + Shift + Espaço não atrapalha o Claude Code.

Exemplo de prompt ditado

“Cria um endpoint POST /pedidos que valida o CPF do cliente, salva no Postgres e escreve os testes com pytest, incluindo o caso de CPF inválido.”

Dica: cuidado com o Esc

No Arara, Esc cancela o ditado. Só que a tecla também chega à janela em foco, e no Claude Code o Esc interrompe o agente quando ele está trabalhando.

Se você costuma ditar o próximo pedido enquanto o Claude ainda roda, desligue Esc cancela nas Configurações do Arara. Para descartar um ditado, aperte o atalho para terminar e apague o texto colado.

Outra ajuda: nomes do seu projeto (tabelas, bibliotecas, siglas) que o modelo erra sempre do mesmo jeito vão para o Dicionário do app. Por exemplo: quando ouvir “pai teste”, escrever pytest.

Perguntas frequentes

Funciona com o Claude Code no Windows?

Sim. O Arara funciona no Windows 10 e 11 em qualquer terminal (Windows Terminal, PowerShell, prompt de comando), no Mac (Apple Silicon ou Intel) e no Linux (beta).

Minha voz ou meu código vão para algum servidor?

O Arara não envia áudio nem texto: a transcrição roda no seu computador com o Whisper (whisper.cpp). O texto colado vai para o Claude Code, que envia o prompt como faria se você tivesse digitado.

Ele entende termos técnicos em inglês no meio do português?

O modelo é configurado para português, e termos comuns como endpoint, pull request ou deploy geralmente saem certos. O que ele errar com frequência você corrige uma vez no Dicionário.

Funciona com Codex, Gemini CLI, Cursor e outros agentes?

Sim. O Arara cola onde está o cursor, então funciona em qualquer agente com caixa de texto, no terminal, na IDE ou no navegador.

Precisa de internet?

Só para baixar o modelo de voz na primeira vez. Depois o ditado funciona offline. O app também consulta se há versão nova, e isso dá para desligar.
