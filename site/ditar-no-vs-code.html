Usos · VS Code

Ditar no VS Code

Dite no chat do Copilot, no terminal integrado (com Claude Code, Codex ou Gemini CLI), em comentários e em mensagens de commit. O mesmo atalho em todo o VS Code e fora dele.

O problema

No VS Code você escreve muito texto que não é código: pedidos para o chat de IA, mensagens de commit, descrições de pull request, comentários e README. É aí que a digitação pesa, e é texto que se fala com facilidade.

A extensão VS Code Speech, da Microsoft, também transcreve no computador, mas só dentro do VS Code. O Arara usa o mesmo atalho no editor, no terminal, no navegador e em qualquer outro app, com o Whisper configurado para português.

Como usar

  1. Baixe e instale o Arara (botões no fim da página). Na primeira vez ele baixa o modelo de voz (o “Preciso”, Whisper large-v3-turbo, tem cerca de 550 MB) e depois fica na bandeja do Windows ou na barra de menus do Mac.
  2. No VS Code, clique onde o texto deve entrar: o campo do chat, o terminal integrado (Ctrl + `), uma linha de comentário ou a caixa de mensagem do Controle do Código-Fonte.
  3. Aperte Ctrl + Shift + Espaço e fale.
  4. Aperte Ctrl + Shift + Espaço de novo. O texto é colado onde está o cursor.
  5. Revise e envie (no chat, Enter; no commit, Ctrl + Enter).

Dica: o VS Code também usa Ctrl + Shift + Espaço

No Windows e no Linux, Ctrl + Shift + Espaço é o atalho do VS Code para mostrar as dicas de parâmetros de uma função. O Arara não “engole” a tecla, então essa janelinha pode aparecer quando você dita dentro de um arquivo de código. É inofensivo.

Se incomodar, remova o atalho do VS Code: Arquivo › Preferências › Atalhos de Teclado, busque por editor.action.triggerParameterHints e apague a combinação. Ou troque o atalho do Arara nas Configurações do app. No Mac, o VS Code usa Cmd + Shift + Espaço para isso, então não há conflito.

A mesma dica vale para editores baseados no VS Code, como Cursor e Windsurf.

Perguntas frequentes

Funciona com o GitHub Copilot Chat?

Sim. Clique no campo do chat, dite e o texto é colado ali. O mesmo vale para as extensões do Claude Code, do Codex e de outros agentes.

Preciso instalar alguma extensão?

Não. O Arara é um app à parte, com atalho global, e funciona em qualquer janela.

Dá para ditar código?

O Arara é melhor para texto: pedidos, explicações, comentários e commits. Ele transcreve o que você fala com pontuação automática, sem comandos de sintaxe como “abre parênteses”.

Funciona no Cursor e no Windsurf?

Sim. Qualquer editor com campo de texto. Veja a dica do atalho acima, que também vale para eles.

O código do meu projeto sai do computador?

Não pelo Arara. Ele só ouve o microfone e cola texto; não lê os seus arquivos e não envia nada para a internet.
